# Modèle : bug connu

À ajouter dans [[Bugs connus]] (ligne au tableau + section), numéro suivant. Le titre de section est **l'identifiant seul** (`## BUG-007`) pour que les ancres `[[Bugs connus#BUG-007]]` fonctionnent. Le statut et la priorité vivent dans [[Backlog]], pas ici.

```markdown
## BUG-0xx
**Sujet en une phrase.** Où dans le code (fichier:ligne), ce qui est attendu, ce qui se passe.
**Scénario** : étapes de reproduction.
**Conséquences** : …
**Piste** : …
```
