# Modèle : entrée de journal

À copier en tête de [[Journal de dev]] (plus récent en haut). Une entrée par session, courte : le *pourquoi*, pas la liste des commits.

```markdown
## AAAA-MM-JJ : titre court
**Objectif** : …
**Fait** : …
**Décidé** : … (→ [[Décisions (ADR)]] si structurant)
**Constaté** : bugs ou surprises (→ [[Bugs connus]])
**Reste / prochain pas** : …
```
